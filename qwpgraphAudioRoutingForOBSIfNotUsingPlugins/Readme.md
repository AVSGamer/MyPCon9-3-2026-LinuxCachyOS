I only use these if there are no available OBS plugins for that "Application Audio Output Capture Source".
It relies on a Audio Patching Software called "qwpgraph".
You create the Audio Output Capture Sources inside OBS first.
Then Identify them in qwpgraph while your game/s are running so you can correct the audio-connection to them, familiarly called audio-patching to sound system people.
Because your patching the audio to be routed to where you want them...
Careful when doing this since it can create that very ear hurting eerie screeching sound that happens when you got a microphone very near a speaker or the speaker outputting the micorphone's input.
