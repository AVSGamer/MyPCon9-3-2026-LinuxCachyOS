Not really supposed to be editing this file but using "addons" to it instead like another file xorg.conf.addon in a extension directory xorg.conf.d where the '.d' stands for directory or a folder. This file is auto-generated by systemd until you start modifying it which can cause instability to your system if done incorrectly.
But I digress, this where I added in Coolbits to be able to undervolt my GPU using nvidia-smi commands and so on.
I also added the Options for defining a custom Virtual Display. Virtual Displays are different from Virtual Desktops. Virtual Desktops are to Windows(Those with Minimize,Maximize, Close buttons on the top right or left of your application "window"/form) as Virtual Displays are to actual Physical Monitors connected via ports on your PC Case, except they are virtual only or emulated per se.
